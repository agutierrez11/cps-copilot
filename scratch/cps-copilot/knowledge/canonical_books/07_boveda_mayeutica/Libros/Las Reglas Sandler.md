# Las Reglas Sandler: Directrices para el Éxito Comercial

**Idea Central**: Un compendio de reglas pragmáticas [[Libros/Porque Fallan Los Vendedores Sandler|diseñadas por David Sandler]] para evitar caer en las trampas tradicionales de ventas (como perseguir al cliente o hacer presentaciones gratuitas) y mantener el control [[Libros/Sandler Training Metodologia Comercial|del proceso comercial mediante]] la descalificación oportuna.

## Reglas Clave Destacadas
1. **Nunca hagas una presentación de ventas hasta que el prospecto esté calificado**: Presentar antes de tiempo es dar consultoría gratuita.
2. **Establece un contrato por adelantado (ANOT)**: Acuerda el objetivo, el tiempo y los posibles resultados antes de iniciar cualquier reunión comercial.
3. **Ninguna reunión de ventas ocurre a menos que el cliente se comprometa a tomar una decisión**: Evita el destructivo *"Déjame pensarlo"*.
4. **Desármate a ti mismo (El vendedor sumiso pero en control)**: Adopta una postura socrática de ignorancia y curiosidad para que el cliente baje las defensas.
